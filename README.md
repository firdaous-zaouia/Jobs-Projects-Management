# Jobs & Projects Management App

Application web développée avec **Angular** permettant de gérer des **emplois** et des **projets** à travers des fonctionnalités CRUD (ajout, modification, suppression).  
Le projet met en œuvre une architecture claire, une gestion d’état avec **NgRx** et une persistance des données via **LocalStorage**.

## 🎯 Objectif du projet

Faciliter la gestion et le suivi des emplois et projets à partir d’une interface simple, intuitive et structurée.  
Ce projet met l’accent sur la logique applicative, la gestion d’état et l’organisation du code.

## ✨ Fonctionnalités

- Création, modification et suppression des **emplois** et des **projets**
- Formulaires dynamiques avec validation
- Gestion d’état centralisée avec **NgRx** (actions, reducers, selectors, effects)
- Sauvegarde des données en **LocalStorage**
- Navigation via le **routing Angular**
- Interface utilisateur basée sur **Bootstrap**

## 🧠 Architecture & concepts

- Architecture modulaire Angular
- Séparation des responsabilités : components / services / store (NgRx)
- Utilisation de modèles (`models`) pour structurer les données
- Gestion des effets
